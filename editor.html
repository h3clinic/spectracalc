How this works

Dots are rebuilt from the published 0.1 nm data pushed back through this page's frozen calibration, so they land on the printed ink exactly as the round-trip validation shows. Edit them and the charts and downloads update live.

Edits live in this browser tab only — this is a static site, so there is no Save to Library and no auto-trace. Download your corrected CSV/Excel, or run the full editor locally for the ink-following auto-trace and writing back to the dataset.
