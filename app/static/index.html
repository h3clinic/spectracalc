Controls

Add Same: click to place dots on the selected curve
+ Add Different: start a NEW spectrum in a fresh color (for merged or missing curves)
Erase: click near a dot to remove it
Chips: click a colored chip to select which curve you're editing
Pan / Scroll: drag to move, scroll to zoom
Ctrl+Z: undo · E / A: select emission / absorption · 1 / 2 / 3: add / erase / pan

After any dot change the bottom panel regenerates each curve's Excel chart, CSV + Excel downloads, and PhotochemCAD-style page.
