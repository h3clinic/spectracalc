Controls

＋ Add: click to place dots on the selected curve
⚡ Auto: click a few dots along missed ink — the program traces the actual ink between them (deterministic, no AI); Esc restarts the chain
⌫ Erase: swipe the brush across dots — anything ≥50% covered along the path is gone; resize with [ and ]. By default it only removes the selected colour, so crossing spectra are safe; press S (or the Erases buttons) to switch between this-colour and all-curves
＋ New: start a NEW spectrum in a fresh color (for merged or missing curves)
Colors: click a swatch in the left rail to select which curve you're editing
Pan / Scroll: drag to move, scroll to zoom
Ctrl+Z: undo · E / A: emission / absorption · 1 / 2 / 3 / 4: add / erase / pan / auto

After any dot change the bottom panel regenerates each curve's Excel chart, CSV + Excel downloads, and PhotochemCAD-style page.
